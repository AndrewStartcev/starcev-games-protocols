# AGENTS.md — Starcev Games Protocols

Этот репозиторий содержит **процесс и стандарты**, а не код конкретной игры.

## Перед изменениями

Прочитать:

1. `README.md`;
2. `docs/00_MASTER_PROTOCOL.md`;
3. документ, который меняется;
4. `research/DECISIONS.md`.

## Правила

- Не добавлять game-specific решения в общий protocol без доказанной повторяемости.
- Platform facts подтверждать официальной документацией.
- Для изменяемых требований обновлять `Last reviewed`/sources.
- Не превращать protocols repo в Godot starter project.
- Не копировать одну и ту же инструкцию в несколько документов: выбрать source of truth и поставить ссылку.
- Изменение обязательного базового решения должно получить запись в `research/DECISIONS.md`.
- При значимом изменении обновить `CHANGELOG.md` и `PROTOCOL_VERSION`.
- Документы должны быть практичными: правила, gate, checklist, templates; минимум теоретической воды.

## Цель

Каждая следующая игра должна требовать меньше повторной работы и меньше контекста, но проходить более стабильный QA.
