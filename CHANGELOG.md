# Changelog

Все значимые изменения протоколов фиксируются здесь.

## 1.0.0 — 2026-09-11

Первый полный production baseline Starcev Games.

Добавлено:

- единый master protocol;
- фильтр идей и Production Score;
- production pipeline с milestone gates;
- архитектура Godot и Web runtime;
- responsive UI/UX;
- asset-first-by-contract pipeline через `ASSET_MANIFEST`;
- platform adapter для Local / Yandex / Pikabu;
- отдельные протоколы Яндекс Игр и Пикабу Игр;
- local-first/cloud save strategy;
- AdsService и monetization rules;
- audio, performance, QA, release;
- портфельная аналитика;
- AI/Codex workflow с экономией контекста;
- backend/security и post-release цикл;
- checklists и шаблоны для каждой новой игры.

Основа решения: официальная документация Godot 4.7.2, Яндекс Игр, Пикабу Игр и web platform APIs. Ссылки — `research/SOURCES.md`.
